# Seed Library 随身资料库 · 实验版

纯静态 Android PWA，支持离线收藏四个平台的分享链接，导入电脑资料快照，搜索和浏览已有文字、笔记及缩略图，导出手机收藏清单。

资料存储在当前设备的 IndexedDB，不随网页发布，不上传到本站。需要定期导出备份。本版没有即时解析、视频下载、Google Drive 自动同步，也不直接修改桌面主库。可以通过 Drive 手动交换 JSON 文件。

使用 HTTPS 打开后，可从 Android Chrome 菜单安装。系统分享入口取决于浏览器安装支持。

本仓库仅含网页程序；不含个人资料、数据库、Google 配置、Cookie 或第三方解析器。
